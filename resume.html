Resume

The résumé is maintained in Overleaf. This page shows the latest public PDF when one is available. Overleaf does not provide a public live-PDF link, so the file is loaded from this site or from a public URL in js/site-config.js.

PDF not published yet

To keep this page current without editing HTML each time, pick one of these:

  • Export the Overleaf PDF to assets/resume.pdf in this repo (simplest; update that file when the résumé changes).
  • Put the PDF on Google Drive or Dropbox with a public link, then set resumePdf in js/site-config.js.
  • Set resumeOverleaf to your Overleaf read-only share link if you want a source shortcut. Recruiters still need a PDF, not the editor.
